Scope: the whole local web app in src/web. Visitor mode: Operate.

Audience and job: one person at a Mac, using it occasionally, turning a stack of cards into checked spreadsheet rows. Important states: no API key, uploading, working, paused, cards to check, photo count to check, ready to copy, pasted and verified. Constraints: every screen explains the next step; a single image can hold 30+ cards.

## Direction contract

THESIS: A calm checking tool that always shows the evidence. It refuses the dashboard of stat tiles: the job is a sentence, a list of what needs you, and one Copy action.

OWN-WORLD: The standard tool look the user chose, at the craft level of Apple Numbers and Linear. System sans, tabular numerals, hairline rules, cool neutrals, one blue for actions and selection, amber only for what needs a person, green only for verified, red only for failure.

STORY: The user drops images, reads what the app is doing in plain words, checks what it flags against the card itself, copies, pastes and confirms the paste matched.

FIRST VIEWPORT: Home shows the drop area as the widest element, options beneath it and earlier scans below. The job page shows a status sentence, tabs Check cards, All cards and Photos, with a fixed Copy bar at the bottom.

FORM: Category standard, played straight, chosen by the user through the standing exit. seed: none (unavailable)

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
